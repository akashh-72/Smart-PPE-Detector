OUR MISSION

Zero Preventable Head & Body Trauma Through Real-Time Edge Intelligence

SafeGuard AI was built to replace slow, fallible manual security turnstile clipboards with deterministic computer vision. Every second a worker operates without an approved helmet or high-visibility garment is a catastrophic hazard.

🧠

YOLOv8 Edge Vision Model

Trained on over 45,000 real-world industrial worksite images across variable lighting, weather, dust, and occlusion conditions. Quantized for sub-150ms execution.

  • Input Resolution: 640 × 640 RGB
  • Runtime: ONNX Runtime Engine
  • Mean Average Precision: 94.2% mAP@0.5
⚡

Micro-Actuator Hardware Controller

Hardware abstraction layer (HAL) connects directly to physical Raspberry Pi 4 GPIO pins or runs in high-fidelity laptop browser simulation mode.

  • Servo Boom Gate: PWM 50Hz (0° closed • 90° open)
  • Character Display: PCF8574 I2C 16x2 LCD
  • Auditory Alert: 2.4kHz Piezoelectric Buzzer
🛡️

Local-First Edge Reliability

Zero internet connectivity required. The gateway operates 100% offline within local intranet security perimeters, eliminating cloud latency and privacy risks.

  • Server: FastAPI Async Event Loop
  • Database: SQLite WAL Mode Engine
  • Telemetry: Real-time WebSockets

Research & Engineering Pedigree

Developed in compliance with the International Safety Equipment Association (ISEA) and OSHA Directorate of Construction guidelines. Designed for plug-and-play retrofit across existing motorized turnstiles, optical flaps, and boom gates.
